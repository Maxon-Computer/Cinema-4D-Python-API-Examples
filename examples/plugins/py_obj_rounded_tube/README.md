# Example py_obj_rounded_tube

Demonstrates how to implement a polygonal object generator with handles to drive parameters.

## DETAILS

The ObjectData plugin builds a polygon object procedurally and exposes handles that let the user drive its shape parameters.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Generating polygon geometry procedurally
- Driving object parameters with handles
