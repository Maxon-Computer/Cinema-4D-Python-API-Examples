# Example py_tool_liquid_painter

Demonstrates how to implement a simple tool.

## DETAILS

The tool combines a metaball and a sphere while illustrating the tool lifecycle, mouse input, viewport drawing, cursor information, and a subdialog.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Implementing a ToolData interaction lifecycle
- Combining metaball and sphere objects for painting
- Handling mouse input and viewport drawing
