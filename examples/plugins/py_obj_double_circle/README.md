# Example py_obj_double_circle

Demonstrates how to implement a spline object generator with handles to drive parameters.

## DETAILS

The ObjectData plugin creates a spline object procedurally, exposes handles for its parameters, and registers a help callback for the generated object.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Generating spline geometry procedurally
- Driving spline parameters with handles
- Providing contextual help for generated objects
