# Example py_cmd_memory_viewer

Demonstrates implementing a simple legacy memory viewer dialog.

## DETAILS

The deprecated example uses a custom GeUserArea to draw memory information and demonstrates how a dialog can provide its own visualization area.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Building a custom GeUserArea visualization
- Displaying memory information in a dialog
