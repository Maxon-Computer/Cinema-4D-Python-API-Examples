# Example py_tool_ui

Demonstrates how to implement a ToolData with a linkBox where it's possible to drag and drop an object, which is then cloned and added to the document in a random position.

## DETAILS

The tool accepts a dragged object, clones it when selected, and inserts the clone into the document at a random position.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Building a ToolData link-box interface
- Cloning dropped objects into the document
