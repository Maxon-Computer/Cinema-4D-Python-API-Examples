# Example py_cmd_sculpt_save_mask

Demonstrates the legacy Sculpting API; it is highly specialized and not that useful outside of sculpting.

## DETAILS

The command finds the first UV tag on a sculpt object, rasterizes the mask, and writes the result to an image file.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Reading sculpt mask data from a sculpt object
- Rasterizing mask data through a UV tag
- Writing the result to a bitmap
