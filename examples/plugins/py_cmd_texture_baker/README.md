# Example py_cmd_texture_baker

Demonstrates implementing a simple legacy texture baking dialog.

## DETAILS

The command bakes the selected object diffuse data to its UV layout and displays the resulting image in the Picture Viewer.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Baking diffuse data to a UV layout
- Displaying generated images in the Picture Viewer
