# Example py_tool_sculpt_grab_brush

Demonstrates how to implement a brush tool that modifies a BaseObject by grabbing all points under the brush.

## DETAILS

The brush finds points under the cursor and moves them according to the grab interaction, illustrating the SculptBrushToolData lifecycle.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Finding points under a sculpt brush
- Moving points with a grab interaction
