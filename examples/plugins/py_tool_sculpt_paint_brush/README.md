# Example py_tool_sculpt_paint_brush

Demonstrates how to implement a brush tool that rasterizes the stencil onto the polygons touched by the brush, accessing the stencil and BodyPaint layer.

## DETAILS

The brush rasterizes the active stencil onto touched polygons and shows how a sculpt brush can access stencil data and a BodyPaint layer.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Rasterizing an active stencil onto polygons
- Accessing sculpt stencil and BodyPaint data
