# Example py_obj_offset_y_spline

Demonstrates a spline offset generator (very questionable design, should not be followed).

## DETAILS

This example responds to a specialized Spline Mask workflow by implementing GetVirtualObjects() and GetContour() together. The design is retained for reference and is not recommended for new plugins.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Generating object and contour output from one plugin
- Handling a specialized Spline Mask workflow
- Understanding a legacy design that is not recommended for new plugins
