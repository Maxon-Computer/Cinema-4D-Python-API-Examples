# Example py_obj_custom_icon

Demonstrates how to implement a scene element that dynamically updates its icon.

## DETAILS

The ObjectData plugin fills custom icon settings from the host node and returns a colorized icon using the Cinema 4D R21 custom icon API.

To run this example, place the file in the Cinema 4D plugins folder and restart Cinema 4D.

Topics:
- Providing custom icon settings for an ObjectData plugin
- Deriving icon colors from a scene element
